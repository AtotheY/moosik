Discord now shows the song title above the artists, with clean cover artwork and a playback progress bar. Friends can open the track in Moosik or listen along while you host. Hosting reconnects automatically if the room expires.

Organize playlists into folders, shuffle a folder, and share a listening recap. You can also sign in using an existing browser login.

This release includes a Debian package for Ubuntu 24.04 on x86-64 alongside the Apple silicon and Windows x64 downloads.
