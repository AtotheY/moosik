**Linux** — `refryt-0.1.14-x86_64.AppImage`: download, `chmod +x`, run. Or use
`scripts/appimage-install.sh install` from source for a desktop launcher entry.

**Linux, Flatpak** — `refryt-0.1.14-x86_64.flatpak`. It isn't on Flathub, so install the file:
`flatpak install --user refryt-0.1.14-x86_64.flatpak`, then `flatpak run io.github.gridoe.refryt`.
It needs the GNOME 51 runtime, which Flatpak offers to fetch the first time. mpv and yt-dlp are
inside. The sandbox can't see your browsers' profile folders, so "Import from a browser" is hidden
and you sign in through the app's own window; "Launch on startup" is hidden too, since a sandboxed
app can't write a login item.

**Windows** — three options for x64, and two for ARM, cross-compiled from Linux with limited testing on real Windows
hardware:
- `refryt-0.1.14-windows-x86_64-setup.exe` — a real installer (Program Files, Start Menu,
  uninstaller). Unsigned, so SmartScreen will warn on first run — expected, not a bug.
- `refryt-0.1.14-windows-x86_64.msi` — the same files as an MSI, for deployment tools or a
  silent install (`msiexec /i refryt-0.1.14-windows-x86_64.msi /qn`). It installs to the same
  folder as the setup, so use one or the other.
- `refryt-0.1.14-windows-x86_64.zip` — portable, no install: unzip and run `refryt.exe`.
  Extract the whole folder before running; the exe needs the DLLs beside it.
- `refryt-0.1.14-windows-arm64.msi` / `.zip` — a native build for Windows on ARM, not yet tested
  on ARM hardware. The x64 files also run there under emulation.

**macOS** — `refryt-0.1.14-macos-arm64.dmg`, for Apple Silicon only. Open it and drag
Refryt to Applications. It is signed ad hoc and not notarized, so
macOS will refuse to open it on the first launch. Run `xattr -cr /Applications/Refryt.app` once,
or allow it in System Settings → Privacy & Security. libmpv and yt-dlp are bundled; nothing needs
installing.

Checksums for every file are in `refryt-0.1.14-SHA256SUMS.txt`.

What changed since 0.1.13:
- **Import from browser, in one click** — Home and Settings have one "Import from browser"
  button. It picks the browser you used most recently and lists only browsers that have a
  sign-in to import; with more than one, a menu lets you choose. New: Firefox forks (Zen,
  LibreWolf, Floorp, Waterfox), Opera, Whale, Helium, and Flatpak and Snap installs on Linux. On
  Windows any Chromium browser without app-bound encryption works, and a browser that holds its
  cookie file locked says to close it and try again. (#9)
- **Volume keys** — Ctrl+↑ and Ctrl+↓ change the volume on Linux and Windows, as ⌘+↑/↓ already
  did on macOS. (#10)
- **Linux tray in the Flatpak** — the tray icon now works there, and it brings the window back
  in front. The Flatpak moves to the GNOME 51 runtime with mpv 0.41.
- **Windows** — the tray icon is sharp instead of a shrunken large icon (#11), and launching
  refryt a second time no longer leaves the X button unable to hide the window (#12).
- **Layout fixes** — track rows keep their number and cover inside the hover highlight, song
  rows on Home have no wide gap when a song has no length, and Ctrl with +, - or 0 no longer
  zooms the layout out of its cards.
