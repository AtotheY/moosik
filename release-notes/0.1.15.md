# Moosik 0.1.15

The first packaged Moosik release for Apple Silicon Macs, with in-app updates hosted on GitHub.

## New

- A dedicated Queue page, plus the same editing controls in the compact and fullscreen queues.
- Drag upcoming songs to reorder them, select several songs together, remove tracks, clear upcoming songs, and undo the last edit.
- Queue moves work with shuffle and preserve the current song and playback position. The edited shuffle order survives relaunch.
- Songs in listening stats use the regular song controls: play, start a mix, and the shared context menu.
- A small update indicator when a new Moosik release is available. Check manually from Moosik → Check for Updates or Settings → About, then install and restart inside the app.
- Signed update archives verified before installation, with queue and settings saved before relaunch.

## Fixes

- Clear status when no update feed has been published, while keeping connection and server errors distinct.
- More reliable signed-in requests and fewer unnecessary Keychain access prompts during session refresh.
- Verified migration of the macOS session to Moosik's Keychain entry.

## Install

Download the macOS ARM64 DMG, open it, and drag Moosik to Applications. Older clients without the updater need this manual installation once; future updates arrive inside the app.

This early release supports Apple Silicon Macs. The installer and update feed declare the minimum macOS version required by the bundled playback libraries. Intel Macs, Windows, and Linux packages are not included in this release.

The app is not Apple-notarized. macOS may ask for approval in System Settings → Privacy & Security on first launch. Updates are independently signed with Moosik's Ed25519 key. Changing from a development build's code-signing identity may also require renewed Keychain approval.

Moosik is an independent GPL-licensed fork of Refryt. This release preserves Refryt's attribution and includes its source history. Listening stats remain local to this installation.
