## macOS media-key fallback

- Added **Settings → System → Media keys → Use Moosik instead of Apple Music**.
- When enabled, Apple Music launch attempts resume Moosik, including when Moosik is closed or after restarting your Mac.
- Normal Play/Pause and other media controls continue working with the active player.
- The setting is off by default and can be turned off at any time. It also blocks manual Apple Music launches while enabled.
- The helper is bundled with Moosik. If macOS requests background activity approval, Settings shows how to finish enabling it.

If you previously installed noTunes separately, quit it and remove its Login Item before enabling Moosik's built-in fallback.
