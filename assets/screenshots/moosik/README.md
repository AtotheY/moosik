# Moosik screenshots

Captured from the native macOS interface of Moosik `0.1.14+ark.7` (source commit `c2fe2ea`). These are actual app captures, not design mockups.

The preview uses a separate profile with credential loading disabled. Browsing pages show public YouTube Music content while signed out. The listening overview uses 1,050 generated listening attempts across 40 public songs from Refryt's existing test fixtures. All listening totals, dates, rankings, ratings, and genre assignments in that demo profile are synthetic, not anyone's personal history.

The interface and themes are the same as the source preview. Only the preview's profile, credential-loading behavior, and window-state paths were isolated for capture. The installed app and its account were not replaced.
